## When to Use

Analyzing competitors and building competitive positioning. Invoke for SWOT analysis, feature benchmarking, pricing comparison, positioning maps, or competitive monitoring — covers direct, indirect, and substitute competitor categories using public sources only.

## Triggers

`competitive analysis`, `SWOT`, `competitor research`, `market positioning`, `competitive intelligence`, `feature benchmarking`, `pricing comparison`, `win/loss analysis`, `white space`

## Key Capabilities

- Identify competitors across direct, indirect, and substitute categories
- Build feature comparison matrices with verified, source-cited evidence
- Analyze pricing strategies and packaging in context
- Map competitor positioning (price vs feature, target segment)
- Track competitor announcements, hiring patterns, and product changes
- Conduct win/loss analysis with sales context
- Identify white space opportunities competitors aren't addressing
- Ethical intelligence gathering (public sources only — no impersonation)
