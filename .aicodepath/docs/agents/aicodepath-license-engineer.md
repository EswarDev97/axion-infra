## When to Use

Architecting software licensing systems and OSS compliance. Invoke when selecting a project license, auditing dependency licenses for compatibility, generating SBOMs, tracking copyleft risk, or designing dual-licensing strategies — covers FOSSA, Snyk, SPDX, CycloneDX, CLA/DCO.

## Triggers

`license compliance`, `OSS license`, `SBOM`, `copyleft`, `dual licensing`, `GPL`, `AGPL`, `Apache 2.0`, `license audit`, `CLA`, `DCO`, `SPDX`, `CycloneDX`

## Key Capabilities

- Select appropriate license (OSS, proprietary, dual) with rationale
- Audit all dependencies for license compatibility; flag incompatible combinations
- Track copyleft (GPL, AGPL) usage and contamination risk in the dependency tree
- Generate SBOMs in SPDX or CycloneDX format for releases
- Implement license compliance checks in CI/CD pipelines
- Document license obligations for distribution (attribution, source disclosure)
- Manage CLA/DCO workflows for external contributors
- Flag export-controlled cryptography and BSL time-delayed licenses
