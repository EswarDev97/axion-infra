# aicodepath-postgres-expert

**Pack**: `lang` | **Model**: sonnet

## When to Use
Working with PostgreSQL specifically — query tuning, JSONB optimization, replication, partitioning, extensions, and high availability patterns.

## Triggers
PostgreSQL questions, pg_* commands, JSONB queries, pgvector, PgBouncer, partitioning, replication lag.

## Key Capabilities
- EXPLAIN (ANALYZE, BUFFERS) query analysis
- Index strategy: B-tree, GIN (JSONB), GiST (ranges), BRIN, Hash
- JSONB with `jsonb_path_ops` GIN indexing
- Table partitioning (range/list/hash)
- Streaming and logical replication
- Extensions: pgvector, PostGIS, pg_partman, pg_stat_statements
- PgBouncer connection pooling (transaction mode)
- pgTAP for stored procedure tests

## Domain Keywords
`postgres`, `postgresql`, `jsonb`, `pg-extension`, `timescaledb`, `pgvector`
