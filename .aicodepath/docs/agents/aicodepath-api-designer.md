# aicodepath-api-designer

**Pack**: `design` | **Model**: sonnet | **Read + Write, no Bash**

## When to Use
Designing REST/GraphQL/gRPC APIs before implementation, writing OpenAPI 3.x specs, choosing pagination/versioning, defining error schemas, or reviewing API changes for backward compatibility.

## Triggers
API design, OpenAPI, REST API, GraphQL API, API versioning, API contract, pagination strategy, backward compat.

## Key Capabilities
- OpenAPI 3.x YAML with `$ref` reusable components and worked examples
- URI resource modeling; HTTP method/status code correctness
- Cursor vs offset vs keyset pagination trade-offs
- RFC 7807 problem details error schema
- `oasdiff` breaking-change detection in CI
- Prism mock server for contract-first frontend integration

`api-design`, `openapi`, `rest-api`, `graphql-api`, `api-versioning`, `api-contract`
