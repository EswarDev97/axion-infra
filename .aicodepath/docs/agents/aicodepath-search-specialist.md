## When to Use

Finding hard-to-locate information. Invoke when standard searches fail, when systematic information retrieval is needed, or when verifying information across multiple sources — covers Boolean operators, advanced search syntax for Google/GitHub/arXiv/Stack Overflow, and specialized academic databases.

## Triggers

`advanced search`, `find information`, `research query`, `source discovery`, `can't find`, `Boolean search`, `Google Scholar`, `arXiv`, `systematic search`, `information retrieval`

## Key Capabilities

- Apply Boolean operators (AND, OR, NOT) and advanced search operators (site:, filetype:, intitle:, inurl:)
- Target specialized sources: GitHub, arXiv, Google Scholar, Semantic Scholar, Stack Overflow, Reddit
- Refine queries iteratively based on result quality
- Filter by date, domain, and language for time-relevant searches
- Document search strategy for reproducibility and handoff
- Triangulate findings across multiple independent sources
- Distinguish verified information from single-source claims
