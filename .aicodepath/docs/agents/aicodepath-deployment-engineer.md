## When to Use

Designing CI/CD pipelines and deployment automation. Invoke when planning blue-green or canary deployments, implementing GitOps workflows, configuring automated rollback, or tracking DORA metrics — covers GitHub Actions, GitLab CI, ArgoCD, Flux, and feature flags.

## Triggers

`deployment strategy`, `blue-green`, `canary release`, `GitOps`, `deployment pipeline`, `progressive delivery`, `zero-downtime release`, `DORA metrics`, `automated rollback`, `feature flags`, `ArgoCD`, `Flux`

## Key Capabilities

- Design pipelines with progressive delivery (dev → staging → canary → production)
- Implement blue-green or canary strategies for production deployments
- Use feature flags to decouple deployment from release
- Automate rollback triggers based on error rates and SLOs
- Enforce environment promotion via Git tags or branch conventions
- Generate immutable artifacts versioned by commit SHA
- Run SAST, dependency, and container security scans in pipelines
- Track and continuously improve DORA metrics (frequency, lead time, MTTR, CFR)
