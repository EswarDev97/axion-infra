# aicodepath-idea-validator

Adversarial product idea validator — competitive teardown, demand verification, differentiation analysis, and decisive go/no-go recommendation before any building begins.

## When to Use

Use during PRE-FLIGHT or INCEPTION when evaluating a new product, feature, or project idea. Triggered by "validate idea", "is this worth building", "go or no-go", "pressure test", "should I build this". Uses web search to find competitors. Never sycophantic — defaults to skepticism until evidence proves otherwise.

## Triggers

- "validate idea", "is this worth building", "go or no-go"
- "pressure test", "idea validation", "should I build this"
- Before investing time in design or implementation for a new product
- When assumed differentiation needs reality-checking against live competitors

## Key Capabilities

- Fatal flaw hypothesis: actively hunts for the mistake or missing demand that kills the project
- Live competitor research via web search — names competitors with traction and weaknesses
- Demand verification: search volume, community discussions, app store reviews, GitHub stars, job postings
- Differentiation analysis: is the advantage real, defensible, and visible to users?
- Go/no-go decision: decisive verdict (GO, NO-GO, or PIVOT TO X) — never hedged
- If idea survives, shifts from flaw-hunting to concrete execution strategy
