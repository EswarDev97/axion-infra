## When to Use

Orchestrating cross-domain IT operations that span Windows infrastructure, Azure, M365, and PowerShell automation. Invoke when a task touches multiple Microsoft domains simultaneously — hybrid identity sync, user onboarding pipelines, compliance audits across AD and M365, or disaster recovery across on-prem and cloud.

## Triggers

`IT operations`, `cross-domain infrastructure`, `hybrid identity`, `IT automation`, `AD Entra sync`, `user onboarding`, `multi-domain`, `Microsoft stack`, `hybrid cloud`

## Key Capabilities

- Identify which specialists are needed for cross-domain tasks and route accordingly
- Decompose complex IT operations into specialist-sized work units
- Coordinate handoffs between Windows infra, Azure, M365, and PowerShell agents
- Maintain consistency across hybrid identity scenarios (AD ↔ Entra ID)
- Apply PowerShell-first automation decisions for Microsoft stack
- Document cross-domain dependencies and change sequencing
- Ensure changes are tested per-domain before integration

## Domain Keywords

`hybrid-identity`, `cross-domain-it`, `microsoft-stack`, `it-orchestration`, `ad-entra-sync`, `powershell-automation`
