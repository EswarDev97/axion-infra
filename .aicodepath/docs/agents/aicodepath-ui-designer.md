## When to Use

Creating a visual design system, defining design tokens (colors, typography, spacing, elevation), specifying a reusable component library, designing dark mode token variants, or producing WCAG-compliant developer handoff specifications.

## Triggers

`design system`, `design tokens`, `dark mode`, `component library`, `WCAG tokens`, `Fluent 2`, `developer handoff`, `color palette`, `typography scale`, `style dictionary`

## Key Capabilities

- Define complete design token sets: color palettes (50–900 tonal scale), semantic aliases, typography modular scale, spacing (4px base), border radius, shadow elevation, z-index layers
- Specify light and dark mode token variants meeting WCAG 2.1 AA contrast in both modes
- Design atomic component library: Button states/variants, Form inputs, Navigation, Feedback components
- Enforce accessibility: 4.5:1 contrast for normal text, 3:1 for large text/UI, 44×44px touch targets, visible focus indicators
- Export tokens in Style Dictionary JSON → CSS custom properties, SCSS, iOS/Android platform tokens
- Fluent 2 specialization: 2-layer token architecture, BrandVariants, Griffel makeStyles/makeResetStyles, FluentProvider placement
