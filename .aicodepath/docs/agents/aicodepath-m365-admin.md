## When to Use

Administering Microsoft 365 services or building M365 automation. Invoke when managing Exchange Online, Teams governance, SharePoint Online permissions, writing Graph API automation, configuring Microsoft Purview retention policies, or implementing Conditional Access for M365 services.

## Triggers

`Microsoft 365`, `Exchange Online`, `Teams admin`, `SharePoint admin`, `Graph API`, `Microsoft Purview`, `M365 PowerShell`, `Teams governance`, `retention policy`, `Conditional Access M365`

## Key Capabilities

- Exchange Online: mailbox provisioning, transport rules, retention policies, mail flow
- Teams governance: creation policies, naming conventions, lifecycle management
- SharePoint Online: site provisioning, permission inheritance, content types
- Microsoft Graph API: bulk operations, user/group management, app registrations with minimal permissions
- M365 PowerShell modules: ExchangeOnlineManagement, MicrosoftTeams, PnP.PowerShell, Microsoft.Graph
- Least-privilege admin roles: Service Admin over Global Admin for service-specific tasks
- Microsoft Purview: compliance policies, DLP rules, sensitivity labels, eDiscovery
- Unified Audit Log: admin activity monitoring, SIEM export, retention
