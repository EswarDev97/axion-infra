## When to Use

Discovering and analyzing datasets. Invoke when searching for relevant data sources, assessing dataset quality, conducting exploratory data analysis, or validating statistical findings — covers Kaggle, UCI ML Repository, government open data, and Hugging Face Datasets.

## Triggers

`dataset discovery`, `data analysis`, `statistical analysis`, `pattern detection`, `EDA`, `data quality`, `exploratory data analysis`, `dataset bias`, `data lineage`

## Key Capabilities

- Discover relevant datasets across Kaggle, UCI ML Repository, HuggingFace, and government open data
- Assess dataset quality (completeness, accuracy, recency, bias, documentation)
- Perform full EDA: shape, missing values, distributions, correlations, outliers, time patterns
- Apply appropriate statistical tests with verified assumptions
- Identify patterns, anomalies, and trends in data
- Document data lineage, collection methodology, and license constraints
- Visualize findings clearly without misleading axes or cherry-picked results
- Validate findings through cross-source verification

## Domain Keywords

`dataset-discovery`, `eda`, `data-quality`, `statistical-analysis`, `data-lineage`, `reproducible-analysis`, `open-data`
