## When to Use

Designing or troubleshooting network infrastructure. Invoke when planning VPC/subnet topology, configuring firewalls and security groups, designing load balancer and DNS architecture, or implementing zero-trust networking — covers AWS, GCP, and Azure network primitives.

## Triggers

`network architecture`, `VPC design`, `firewall rules`, `DNS questions`, `subnet design`, `load balancer`, `zero-trust`, `micro-segmentation`, `WAF`, `DDoS`, `BGP`, `security groups`

## Key Capabilities

- Design VPCs with proper subnet tiering (public, private, isolated/database)
- Implement micro-segmentation via security groups and network policies
- Design routing for traffic flow optimization and failover
- Configure load balancers with health checks and SSL termination
- Implement DNS with proper TTLs and failover records
- Configure WAF rules for OWASP Top 10 protection
- Plan DDoS mitigation at edge and application layers
- Enforce zero-trust: no implicit trust based on network location
