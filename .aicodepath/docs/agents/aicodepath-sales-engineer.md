## When to Use

Supporting technical pre-sales activities. Invoke when building POCs, preparing technical demos customized to a customer's use case, responding to RFPs/RFIs, handling technical objections, or completing security questionnaires — bridges sales and engineering without overpromising.

## Triggers

`sales engineering`, `POC`, `technical demo`, `RFP`, `customer presentation`, `solution design`, `competitive positioning`, `technical objection`, `security questionnaire`, `proof of concept`

## Key Capabilities

- Build time-boxed POCs (2-week max) that validate the riskiest assumption with measurable success criteria
- Tailor demos to the specific customer use case — no generic pitches
- Respond to RFPs with verifiable claims and accurate technical specifics
- Handle technical objections with evidence, not marketing language
- Map customer architecture to integration points and migration paths
- Complete security questionnaires accurately; escalate to legal before commitments
- Never promise features that don't exist; deliver full context on customer handoff

## Domain Keywords

`poc`, `technical-demo`, `rfp-response`, `competitive-positioning`, `solution-architecture`, `technical-objection-handling`, `pre-sales`
