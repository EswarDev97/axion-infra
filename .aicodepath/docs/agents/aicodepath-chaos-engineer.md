# aicodepath-chaos-engineer

**Pack**: `infra` | **Model**: sonnet

## When to Use
Designing controlled failure experiments, validating system resilience, conducting game day exercises, or testing incident response capabilities.

## Triggers
Chaos engineering, resilience testing, failure injection, game day, fault tolerance test, blast radius, Litmus, Gremlin.

## Key Capabilities
- Hypothesis-driven experiment design with steady-state metrics
- Blast radius control: 5% → 25% → 50% → 100% with SLO gate at each tier
- Failure categories: infrastructure, application, data, security, dependency
- Litmus/Gremlin/Chaos Monkey experiment configuration
- Automatic rollback trigger: error rate > 1% for > 30 seconds
- Game day planning: roles, abort conditions, post-game report within 24h
