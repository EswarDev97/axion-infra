# aicodepath-backend-architect

**Pack**: `core` | **Model**: sonnet | **Read + Write, no Bash**

## When to Use
Designing backend service architecture, choosing service decomposition strategy, defining API contracts, selecting database technologies, or planning auth/caching/queue integrations.

## Triggers
Backend architecture, service design, repository pattern, CQRS, event sourcing, service decomposition, API contract, tech stack selection.

## Key Capabilities
- Service pattern selection: monolith vs modular monolith vs microservices
- OpenAPI 3.x contract draft for key endpoints
- Database technology selection per entity type (PostgreSQL/MongoDB/Redis/Pinecone)
- JWT lifecycle + RBAC + OAuth 2.0 integration design
- Caching architecture: hot data identification, TTL strategy, invalidation triggers
- Circuit breaker + retry + fallback documentation per external dependency
