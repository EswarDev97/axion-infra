## When to Use

Optimizing for organic search visibility. Invoke when conducting technical SEO audits, implementing structured data (Schema.org JSON-LD), improving Core Web Vitals, building keyword strategies, setting up international targeting (hreflang), or reviewing content for E-E-A-T signals. White-hat techniques only.

## Triggers

`SEO audit`, `keyword research`, `search rankings`, `structured data`, `schema.org`, `Core Web Vitals`, `technical SEO`, `hreflang`, `sitemap`, `robots.txt`, `canonical URLs`, `E-E-A-T`

## Key Capabilities

- Technical SEO: crawlability, indexability, mobile-friendliness, HTTPS, canonical URLs
- Structured data: JSON-LD for rich results (Schema.org validation)
- Core Web Vitals: LCP < 2.5s, CLS < 0.1, INP < 200ms — CI budget enforcement
- Keyword research: intent classification (informational/navigational/transactional/commercial)
- Meta optimization: title 50-60 chars, description 150-160 chars
- International: hreflang for multilingual/multiregional targeting
- XML sitemap generation and search console submission automation
- Content strategy: topical authority, internal linking with descriptive anchors, E-E-A-T
