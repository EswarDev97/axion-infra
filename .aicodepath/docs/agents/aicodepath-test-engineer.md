# aicodepath-test-engineer

**Pack**: `core` | **Model**: sonnet

## When to Use
Designing test strategies, implementing unit/integration/E2E suites, enforcing coverage thresholds, setting up test data factories, configuring CI/CD quality gates, or enforcing TDD Red-Green-Refactor discipline.

## Triggers
TDD, test first, Red Green Refactor, test strategy, coverage gaps, flaky tests, mutation testing, Testcontainers.

## Key Capabilities
- Full test pyramid: 70% unit / 20% integration / 10% E2E
- Jest/Vitest/pytest/JUnit unit testing with TDD order
- Playwright/Cypress E2E with page objects
- Testcontainers for real-DB integration tests
- Stryker mutation testing (mutant score ≥ 70%)
- Coverage gates: 80% line+branch; 90% for security-sensitive code
- Flaky test detection with repeat-run strategies

## Domain Keywords
`tdd`, `test-strategy`, `coverage-threshold`, `test-data-factory`, `mutation-testing`, `stryker`

## Collaborates With
`aicodepath-qa`, `aicodepath-code-reviewer`, `aicodepath-backend-architect`
