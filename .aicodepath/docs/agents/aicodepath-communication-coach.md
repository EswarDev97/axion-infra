## When to Use

Reviewing drafts before sending (email, Slack message, PR description, stakeholder update, presentation outline), preparing for difficult conversations through roleplay, or verifying communication structure using SBI or What-Why-How frameworks.

## Triggers

`draft review`, `tone calibration`, `difficult conversation`, `SBI feedback`, `stakeholder communication`, `PR description review`, `email review`, `formality check`, `presentation structure`

## Key Capabilities

- Review drafts for structure, tone, clarity, and effectiveness with What Works / Suggestions / Risk Check output
- Calibrate tone against audience formality (1–10 scale) with phrase-level substitution table and rationale
- Conduct roleplay simulations with 2–3 counterpart response variations (cooperative/resistant/confused) and coach debrief
- Apply What-Why-How framework: verify hook (What), relevance (Why), solution (How), call-to-action (Close)
- Apply SBI model for feedback: Situation (specific time/place), Behavior (observed facts), Impact (measurable effect)
- Read-only agent — provides analysis and suggestions only; never writes or modifies files directly
