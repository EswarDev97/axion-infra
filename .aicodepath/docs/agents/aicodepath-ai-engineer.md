## When to Use

Integrating AI capabilities into applications. Invoke when selecting between proprietary and open-source models, designing API integration patterns (OpenAI, Anthropic, Hugging Face), implementing accuracy benchmarking and A/B testing, applying ethical guardrails, or setting up drift monitoring for production AI systems.

## Triggers

`AI integration`, `model selection`, `AI accuracy tuning`, `ethical AI`, `bias detection`, `explainability`, `model drift`, `A/B testing models`, `AI governance`, `SHAP`, `LIME`

## Key Capabilities

- Model selection: accuracy/cost/latency trade-offs; justify against requirements before picking largest
- API integration: retry logic, timeout, fallback when AI service unavailable
- Accuracy benchmarking on representative test data; A/B testing framework for model version comparison
- Bias detection on training data and predictions; required before deployment
- Explainability: LIME, SHAP for high-stakes decisions
- Ethical guardrails: fairness checks, output filtering, PII protection in training data
- Production drift monitoring: alert on prediction distribution shift
- AI governance documentation: model decisions, versioned artifacts
