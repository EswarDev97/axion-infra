# aicodepath-performance-engineer

**Pack**: `quality` | **Model**: sonnet

## When to Use
Writing DB queries under high traffic, profiling slow API endpoints, optimizing large dataset loops, implementing caching strategies, or investigating N+1 queries and memory leaks.

## Triggers
Performance bottleneck, slow endpoint (>200ms p95), N+1 query, memory leak, caching strategy, load testing, flame graph, Core Web Vitals.

## Key Capabilities
- EXPLAIN ANALYZE and N+1 ORM detection
- Redis cache-aside pattern with TTL and invalidation
- 0x / clinic.js flame graphs for Node.js; cProfile / py-spy for Python
- k6, Artillery, JMeter load testing (baseline → profile → optimize → verify)
- Core Web Vitals: LCP, INP, CLS optimization
- `CREATE INDEX CONCURRENTLY` deployment discipline

`performance-engineering`, `profiling`, `n-plus-one`, `caching-strategy`, `memory-leak`, `load-testing`
