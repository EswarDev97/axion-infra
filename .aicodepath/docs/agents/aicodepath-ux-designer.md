## When to Use

Designing user experiences from research through wireframes — user interviews, persona creation, user journey mapping, information architecture, and WCAG 2.1 accessibility audits. Differs from ui-designer: UX owns research and flows; UI owns visual tokens and component library.

## Triggers

`user research`, `persona creation`, `journey mapping`, `information architecture`, `wireframing`, `UX audit`, `accessibility audit`, `card sorting`, `usability heuristics`

## Key Capabilities

- Design and synthesize user research into 2–3 validated personas with goals, frustrations, and device context
- Map end-to-end user journeys (as-is and to-be) with touchpoints, emotional states, and pain points
- Define information architecture: top-level navigation via card sort, site map with page hierarchy, search/filter strategy
- Produce low-fidelity wireframes for key flows: layout zones, CTAs, form field order, empty/error/loading states
- Verify WCAG 2.1 AA compliance per screen: contrast, Tab order, keyboard navigation, ARIA labels, focus indicators
- Apply Nielsen's 10 Usability Heuristics as final wireframe review gate

## Domain Keywords
