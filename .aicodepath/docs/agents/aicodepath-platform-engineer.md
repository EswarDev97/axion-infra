## When to Use

Building or improving internal developer platforms (IDPs). Invoke when designing Backstage developer portals, creating golden path templates, building service catalogs with ownership tracking, implementing GitOps self-service workflows, or designing multi-tenant platform APIs with RBAC.

## Triggers

`internal platform`, `developer portal`, `golden path`, `Backstage`, `platform engineering`, `service catalog`, `IDP`, `developer self-service`, `GitOps platform`, `DORA metrics`, `developer experience`

## Key Capabilities

- Backstage developer portal: plugin architecture, entity definitions, software catalog, TechDocs
- Golden path templates for common service types (web service, worker, library, data pipeline)
- Self-service provisioning: one-click environments, database creation, CI/CD pipeline generation
- Service catalog: ownership tracking, dependency mapping, SLA visibility
- Platform RBAC: team-based isolation with least-privilege self-service
- GitOps workflows: ArgoCD/Flux integration for declarative platform state
- Developer experience metrics: DORA metrics, deployment frequency, lead time, MTTR
- Cost allocation per team/service with monthly visibility reports
