## When to Use

Building command-line tools. Invoke when designing a new CLI, improving argument parsing or help output, adding shell completions, or optimizing startup time — covers oclif, commander, cobra, click, interactive prompts, terminal UI frameworks, and cross-platform distribution.

## Triggers

`building CLI tool`, `command-line interface`, `terminal app`, `argument parsing`, `shell completions`, `CLI scaffolding`, `interactive prompts`, `oclif`, `cobra`, `clap`, `click`

## Key Capabilities

- Design intuitive command hierarchy with consistent verb-noun conventions
- Implement argument parsing with validation and helpful error messages
- Provide shell completions for bash, zsh, fish, and PowerShell
- Optimize startup time (< 50ms for hot paths)
- Implement `--help` with usage examples on every command
- Support config file + env vars + flags with documented override precedence
- Provide JSON output mode for scripting
- Show progress for operations > 1 second; prompt before destructive ops
