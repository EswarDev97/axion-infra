## Overview

Run Claude Code sub-agents in the background while you keep working. True parallel AI
development that eliminates blocking.

## Key Functionality

- Press **`Ctrl+B`** to background sub-agents during execution, enabling continued work on
  other tasks simultaneously.
- Use `/tasks` to check "status, token usage, and progress" of background processes.

## Ideal Use Cases

- Research
- Code analysis
- Documentation
- Security audits
- Performance profiling

Keep **foreground-intensive work** — tasks requiring user input or file modifications — in
the main session.

## Companion Tools

- `/compact` — instant context compaction
- `/stats` — dashboard for usage patterns
- `/rename` — session naming
- `--agent` flag — debug specific sub-agents in isolation

## Practical Guidance

> "Backgrounding requires timing it while the agent is actively running, not after it
> completes."

Claude Code becomes "a parallel development environment."
