## Core Principles

- **Specify output shape, not just goals** — "Create endpoints at these routes with Zod validation" beats generic requests
- **Name constraints upfront** — Tech stack, error handling, and styling choices should be explicit
- **Include non-obvious requirements** — Rate limiting, idempotency, and loading states separate demos from production

> "The difference between a prompt that produces throwaway code and one that generates
> production-ready output comes down to specificity."
