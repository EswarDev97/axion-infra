## The /init Command

Starting any new project with `/init` generates a tailored `CLAUDE.md` file. The command
"scans your project and creates instructions" covering frameworks, build patterns, file
structure, and code style preferences.

## Template Customization Workflow

1. Clone and understand a template.
2. Customize the tech stack.
3. Save conventions to `CLAUDE.md` for future sessions.

## Convention Storage

Document patterns directly in `CLAUDE.md`. Adding sections like API route specifications or
database patterns means "Claude applies these conventions automatically" without repeated
explanations.

## Practical Application

Claude reads `CLAUDE.md` from the project root at session start, enabling persistent
configuration across multiple work sessions. For teams building frequently, this eliminates
repetitive setup overhead.
