# Installation

AICodePath is a Claude Code plugin. It runs inside Claude Code sessions and requires no separate process.

---

## Prerequisites

### Required

| Tool | Minimum | How to install | Verify |
|------|---------|---------------|--------|
| Claude Code | Latest | [claude.ai/code](https://claude.ai/code) | `claude --version` |
| Node.js | 18+ | [nodejs.org](https://nodejs.org) or `brew install node` | `node --version` |
| npm | 9+ | Bundled with Node.js | `npm --version` |
| Git | Any | [git-scm.com](https://git-scm.com) or `brew install git` | `git --version` |

SQLite3 is **not** a system prerequisite — it's bundled via the `better-sqlite3` npm package and installed automatically during `npm install`.

### Optional

| Tool | Purpose | How to install |
|------|---------|---------------|
| GitHub CLI (`gh`) | Release automation (`/aicodepath-release`), CI/CD auto-recovery (`aicodepath-ci-fixer` agent) | `brew install gh` / [cli.github.com](https://cli.github.com) |
| Python 3 | Higher-confidence diagram generators (85–95% vs 60–70% without it) | `brew install python3` / [python.org](https://python.org) |

Install optional Python dependencies if using diagram generation:

```bash
pip3 install -r .aicodepath/generators/requirements.txt
```

## New Project Setup

```bash
# 1. Clone or create your project
git clone <your-repo> my-project
cd my-project

# 2. Copy AICodePath into the project
cp -r /path/to/aicodepath-tool/.aicodepath .

# 3. Install Node dependencies
cd .aicodepath && npm install && cd ..

# 4. Initialize (creates .claude/ symlinks, settings.json, DB, MCP config)
node .aicodepath/bin/aicodepath.js init

# 5. Install DB schema (42 tables + FTS indexes)
bash .aicodepath/scripts/init-knowledge-base.sh

# 6. (Optional) Install git pre-commit hooks
bash .aicodepath/scripts/install-git-hooks.sh

# 7. Open Claude Code
claude
```

---

## Existing Project Setup

Same steps as above. The `init` command is safe to run on existing projects — it only adds `.claude/` symlinks and generates `settings.json`; it does not modify your source code.

---

## What `init` Creates

```
.claude/
├── settings.json          # Hook registrations with absolute paths
├── skills/                # Symlinks → .aicodepath/skills/
├── agents/                # Symlinks → .aicodepath/agents/
└── rules/                 # Schema context cache (auto-generated)

.aicodepath/
└── config.json            # Feature flags and project config (created if missing)
```

# Check all components are healthy

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `AICODEPATH_DB_PATH` | `aicodepath-docs/aicodepath.db` | Override DB file location |
| `AICODEPATH_GICL_DISABLED` | `false` | Set `true` to disable GICL (use feature flag instead) |
| `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS` | unset | Set `1` to enable swarm feature |

Configure in `.env.aicodepath` (auto-generated by init):

```bash
# .env.aicodepath
AICODEPATH_DB_PATH=aicodepath-docs/aicodepath.db
# AICODEPATH_GICL_DISABLED=true
```

## Updating AICodePath

When a new version of AICodePath is released, use the `update` command to sync framework files into your project without touching your customizations.

### What it does

- Adds new framework files (hooks, skills, agents, libs, scripts, etc.)
- Updates existing framework files to the latest version
- **Never deletes** files you added to `.aicodepath/`
- Skips `config.json` and `codebase-map.md` (your project-specific overrides)
- Applies any new DB migrations
- Re-runs `aicodepath init` to regenerate `settings.json` and symlinks

### Usage

`cd` into the project you want to update, then run the CLI from there. `--source` points to the freshly cloned `aicodepath-tool` repo containing the new version.

```bash
cd ~/workspace/myproject

# Preview what would change without touching anything:
node .aicodepath/bin/aicodepath.js update --source ~/workspace/aicodepath-tool --dry-run

# Apply the update:
node .aicodepath/bin/aicodepath.js update --source ~/workspace/aicodepath-tool
```

> **Why run it from the target project?** `install-v2.sh` installs `node_modules` into the target project's `.aicodepath/`. Running the CLI from a bare `aicodepath-tool` clone will fail with `Cannot find module 'commander'`.

### What happens step by step

1. **Diff check** — lists every file that exists in both source and target but differs. You'll see a "WILL OVERWRITE (modified):" list and be asked to confirm before anything changes.
2. **Backup** — creates `.aicodepath.backup.YYYYMMDD_HHMMSS/` in the target project before touching anything.
3. **rsync** — syncs `hooks/`, `lib/`, `skills/`, `agents/`, `guidelines/`, `db/`, `scripts/`, `bin/`, `templates/`, `rules/`, `docs/`, `commands/`.
4. **Top-level files** — copies `version`, `package.json`, `claude-code-official-spec.md`, `plugin.json`, and root `VERSION`.
5. **DB migrations** — applies any `.sql` files in `db/migrations/` that are absent from the target (in sort order). Stops with exit 1 on failure.
6. **Init** — runs `aicodepath init` to regenerate `settings.json` and recreate any missing `.claude/skills/` and `.claude/agents/` symlinks.

### After updating

New skills and agents appear automatically once `init` runs. No manual symlink management needed.

```bash
# Verify the new skills/agents are available:
ls .claude/skills/
ls .claude/agents/

# Check the new version:
cat .aicodepath/version
```

### Recovering from a bad update

The backup created in step 2 is a complete copy. To restore:

```bash
rm -rf .aicodepath
mv .aicodepath.backup.YYYYMMDD_HHMMSS .aicodepath
node .aicodepath/bin/aicodepath.js init
```

## Troubleshooting Installation

**Hooks not firing:**
```bash
# Regenerate settings.json
node .aicodepath/bin/aicodepath.js init

# Verify hook paths exist
cat .claude/settings.json | grep hooks
```

**DB errors on startup:**
```bash
# Re-initialize the database
bash .aicodepath/scripts/init-knowledge-base.sh
```

**Skills not loading:**
```bash
# Check symlinks
ls -la .claude/skills/

# Re-run init if symlinks are broken
node .aicodepath/bin/aicodepath.js init
```

See `.aicodepath/docs/user-guide/troubleshooting.md` for more.
