# Research Mode Context

## When Active

During `/aicodepath-research-mode` skill execution and INCEPTION phase exploration.

## Process

1. Understand -- clarify the problem and constraints.
2. Explore -- search the codebase and external sources.
3. Hypothesize -- form candidate explanations or designs.
4. Verify -- test hypotheses against evidence.
5. Summarize -- document findings with source references.

## Behavioral Bias

- Understand before acting.
- Do not write code until understanding is clear.
- Ask clarifying questions when ambiguity exists.
- Document findings with source references.

## Tool Preference

Prefer: Read, Grep, Glob, WebSearch, Context7 MCP.

Avoid: Write, Edit -- until research is complete and a conclusion is formed.

## Does NOT Override

The existing `aicodepath-research-mode` skill workflow. This mode provides
behavioral guidance within that workflow.
