# Retrospective Format Reference

Append to `aicodepath-docs/knowledge.md` when writing a session retrospective.

```markdown
## Retrospective: {session-topic} — {date}
**Duration**: {N} iterations / {N} tasks completed
**Final Score**: {score}/100

### What Worked
- {implementation pattern, tool, or approach that produced good results}

### What Slowed Us Down
- {blocker, false start, or repeated error that cost iterations}

### Lessons for Next Time
- {specific, actionable change — "use X instead of Y for Z situations"}

### Reflexion Patterns Recorded
- {error type}: {resolution} (will prevent re-investigation)
```

Three sentences written now prevent three hours of re-investigation in the next session.
