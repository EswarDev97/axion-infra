## Growth Loops

For `$ARGUMENTS`, identify which growth loop(s) apply:

```
VIRAL LOOP:
User uses product → Gets value → Shares/invites others → New user uses product
Example: Dropbox "share a folder", Slack workspace invites

USAGE LOOP:
User uses product → Creates content/data → Product improves → More users
Example: Spotify playlists, YouTube algorithm

COLLABORATION LOOP:
User completes a task → Invites collaborator to review/contribute → Collaborator becomes user
Example: Figma "share for review", Notion page sharing

USER-GENERATED LOOP:
User creates public content → SEO/social discovery → New user finds content → Signs up
Example: Product Hunt, Reddit, Stack Overflow

REFERRAL LOOP:
User gets value → Incentivized to refer → Friend signs up → Both get reward
Example: Dropbox 500MB bonus, Robinhood free stock
```

Recommend 1-2 loops for the product. Design the specific mechanics:
- Entry point (what triggers the loop?)
- Value event (what makes someone want to share/invite?)
- Conversion (how does a new person become a user?)
- Measurement (what's the K-factor / viral coefficient?)
