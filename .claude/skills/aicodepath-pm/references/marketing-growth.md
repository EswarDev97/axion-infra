- Own a word or concept in the customer's mind
- Position against the leader OR in a new category you define


## North Star Metric

For `$ARGUMENTS`, identify the NSM and supporting input metrics.

**Game type classification (Sean Ellis):**
- **Attention game** — value = time/engagement (e.g., Spotify, TikTok)
  NSM candidates: DAU, session length, content consumed per user
- **Transaction game** — value = commerce/conversions (e.g., Shopify, Stripe)
  NSM candidates: GMV, transactions/user/month, successful payments
- **Productivity game** — value = work done / time saved (e.g., Slack, Notion, Figma)
  NSM candidates: tasks completed, docs created, messages sent

```markdown
## North Star Metric — [Product]

**Game type:** [Attention / Transaction / Productivity]

**North Star Metric:**
Name: [Metric name]
Definition: [Exact formula — no ambiguity]
Current value: [If known]
Target: [X] by [Date]

**Why this metric:**
[Why it best represents value delivered to users AND business health]

| [M3] | [Mechanism] | | |

**Counter-metrics (guardrails):**
| Metric | Must not drop below |
|--------|---------------------|
```
