# PM Discovery Artifact Schema

Artifacts produced by the PM Discovery Gate during AIDLC greenfield inception.
Generated by one of three routes: web research, user description, or AI hypothesis.
Written to `aicodepath-docs/pm/` (directory created at runtime by inception.md).

## Required Files

### hypothesis-personas.md
**Purpose**: User personas grounding who the product is built for
**Required frontmatter**:
- `**Generated**: YYYY-MM-DD`
- `**Source:** Web Research | User-Provided | AI Hypothesis`
**Content**: 2–3 personas, each with: Role/Context, Problem, Current Solution,
            Frustrations, Switch Trigger
**Route C only**: include `⚠️ AI HYPOTHESIS — Not based on research. Validate before architecture locks.`

### competitive-awareness.md
**Purpose**: Competitive landscape so brainstorm designs differentiated solutions
**Required frontmatter**:
- `**Generated**: YYYY-MM-DD`
- `**Source:** Web Research | User-Provided | AI Hypothesis`
**Content**: 3–5 named tools, each with: Name, What it does well, Where it falls
            short, Why users switch away

## Staleness Rule
If `Generated:` date is >90 days old, the session-start gate re-prompts:
"PM artifacts are N days old — still current for this product direction? [Yes / Regenerate]"

## Source Values
| Value | Meaning |
|-------|---------|
| `Web Research` | Generated from live web search via /aicodepath-research-mode |
| `User-Provided` | Synthesized from user answers to 3 structured questions |
| `AI Hypothesis` | AI-generated from domain name alone — lowest confidence, explicit opt-in |
